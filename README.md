# Задание 1. Список предложений

Запуск:

```bash
npm install
npm run dev
```

Компонент `Listing` принимает `items: ListingItem[]`, по умолчанию пустой массив. В `App.tsx` в него передаются данные из `src/data/etsy.json`.

По заданию реализованы сокращение названий до 50 символов с `…`, оформление валют USD/EUR/GBP и иных кодов, а также классы остатков `stock-low`, `stock-medium`, `stock-high`. Неполные позиции из исходного JSON не выводятся. Карточки ведут на страницу товара.

Этот проект предназначен для **отдельного GitHub-репозитория** (например, `netology-props-listing`). В корень репозитория загружай содержимое этой папки, не вложенную папку `listing`.
